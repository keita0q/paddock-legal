プライバシーポリシー

最終更新日：2026年6月20日

アプリ「パドック動画解析（PaddockScope）」（以下「本アプリ」）における利用者情報の取扱いについて定めます。

1. 取得する情報

本アプリはアカウント登録を必要とせず、氏名・住所・電話番号などの個人を直接特定する情報は取得しません。取得・保存するのは以下です。

  • 撮影・選択した動画：パドックのスコア算出のためサーバへ送信します。処理に用いた一時データは順次削除します。
  • レース記録：予想印・観察スコア（イレ込み・歩様）・市場情報（人気・オッズ・馬体重）・確定着順などを、振り返りのためクラウド（Google Cloud Storage）へ保存します。
  • 端末内データ：お気に入りの馬・通知設定・表示キャッシュはお使いの端末内のみに保存します（サーバへ送信しません）。
  • 権限：カメラ（ライブ検出）・写真ライブラリ（動画選択）・通知（発走リマインダー）。許可があった場合のみ使用します。

2. 利用目的

  • パドックの状態スコアの算出・表示、レースの振り返り・記録のため。
  • 本アプリの品質改善・不具合調査のため。

3. 第三者提供・データ源

  • 取得した記録を第三者へ販売・提供することはありません。
  • 広告SDK・行動トラッキングは使用しません。
  • 出馬表・成績・血統・オッズ・人気・確定着順などの競馬情報は、外部サービス由来の情報を個人利用の範囲で取得して表示しています。これら情報の正確性・最新性は保証されません。
  • データの保存・処理基盤として Google Cloud Platform（Cloud Storage / Cloud Run、リージョン：東京）を利用します。

4. 保存期間・削除

  • レース記録は振り返りの目的で保存します。アプリの「設定 → データ管理」から削除できます。
  • 採点のため送信された動画は、処理後の一時データを順次削除します。
  • 端末内データ（お気に入り・設定・キャッシュ）はアプリの削除等で消去できます。

5. 安全管理

通信は HTTPS で暗号化します。サーバ基盤のアクセス権限は必要最小限に管理します。

6. 子どもの利用

本アプリは競馬情報を扱うため、17歳以上の利用を想定しています。子どもを対象としたサービスではありません。

7. 改定

本ポリシーは必要に応じて改定します。重要な変更がある場合はアプリ内等でお知らせします。

8. お問い合わせ

本アプリに関するお問い合わせは、App Store の開発者連絡先までお願いいたします。
